Evidence by referent
====================

The reverse view of the corpus: for each thing the system describes, the
sources that say something about it, and the claim each one makes. Where
:doc:`Sources <sources/index>` groups evidence by *where it came from*, this groups
the same evidence by *what it supports* — one page per referent.
